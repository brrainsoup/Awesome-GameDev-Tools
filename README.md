# Awesome-GameDev-Tools

These are some tools that I think can be helpful for game development.

1. Notepad++
  * An alternative to Notepad that supports more intense note taking and/or coding. Notepad++ can create projects in tabs rather than opening new windows, and also has colored text to show errors.

2. TexturePacker
  * https://www.codeandweb.com/texturepacker
  * Texturepacker is a program that can help create sprite sheets and make the process a lot simpler than if you were to do it yourself. Will also trim sprites and remove duplicates to optimize your files.

3. Paint.Net
  * https://paint.net/
  * Free editing software that can be used to create basic ui or even sprites.

4. Spacescape
  * http://alexcpeterson.com/spacescape/
  * A website that can be used to generate custom space-themed skyboxes for games.

5. Chiptone
  * https://sfbgames.itch.io/chiptone
  * A helpful program used to create your own sound effects

6. EZ Sound Preview
  * https://rugbugredfern.itch.io/ezsound
  * EZ Sound Preview will allow you to go through sounds within large packs to make the process faster

7. Poly Pizza
  * https://poly.pizza/
  * Has a bunch of free to use low poly assets

8. Screentogif
  * https://nicke.tech/n-studio?migrated=true
  * Video recording tool that can be used to make short videos or gifs for marketing

9. Everything
  * https://www.voidtools.com/
  * Quickly searched through all your files to find what you're looking for

10. Desmos
  * https://www.desmos.com/
  * A math tool that can help you visualize formulas
